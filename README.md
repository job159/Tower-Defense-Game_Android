# 霓虹防線 NEON BASTION

3D 科幻霓虹風格塔防遊戲。Android App（WebView 包裝）＋ 瀏覽器皆可玩，完全離線、不需任何網路資源。

- **利息經濟**：每波開始時依存款獲得利息，存錢與擴張之間要取捨
- **圖鑑**：全砲塔／敵人資料與剋制表
- **全新音訊引擎**：程序化合成的電影級音效與多段式動態配樂（詳見下方「音效與配樂」）
- 即時 3D 場景：HDR 泛光、即時陰影、GPU instancing、粒子與光束特效，畫質自動分級

## 區網分發（不經過網際網路）

開發時也可以直接從這台電腦把 APK 傳到同一個 Wi-Fi 下的手機：

1. 電腦與手機連同一個 Wi-Fi。
2. 在專案資料夾執行：
   ```bash
   npm run serve
   ```
3. 用電腦瀏覽器開 `http://localhost:8765/qr`，手機相機掃畫面上的 QR 碼。
4. 手機開啟下載頁 →「下載 APK」→ 開啟檔案 → 依提示允許「安裝未知應用程式」→ 安裝。
   - 瀏覽器若提示「不安全的下載」，選「保留／仍要下載」（區網 http 的正常提示）。
   - Play 安全防護若詢問，選「仍要安裝」（自己簽署的 App 都會這樣）。
5. 下載頁也有「在瀏覽器直接試玩」，不用安裝就能玩（`/play/`）。

> 如果手機連不上：確認 Windows 防火牆允許 Node.js 的連入連線，或把 Wi-Fi 設為「私人網路」。

## 開發

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 開發伺服器 `http://localhost:5173`（改程式自動重建） |
| `npm run build` | 產生網頁版 `dist/www/` 並打包簽署 `dist/NeonBastion.apk` |
| `npm run build:web` | 只建網頁版 |
| `npm run build:apk` | 只打包 APK（`-- -Debug` 可產生可用 chrome://inspect 除錯的版本） |
| `npm run serve` | 區網下載伺服器＋ QR 碼頁面 |
| `npm run build:site` | 產生公開下載頁＋網頁版 `dist/site/`（GitHub Pages 用，平常由 GitHub Actions 自動執行） |
| `npm run release` | 把 `dist/NeonBastion.apk` 上傳成 GitHub Release `v<版本>`（`-- --notes "更新內容"`） |
| `npm run sim` | 無畫面平衡模擬：機器人自動玩全部關卡（`-- --diff all --research full --seeds 3 --verbose`） |

建置 APK 需要 JDK 17 與 Android SDK（已安裝在 `%LOCALAPPDATA%\Programs\jdk-17` 與 `%LOCALAPPDATA%\Android\Sdk`），不需要 Gradle 或 Android Studio。

**發佈新版本**
1. 修改 `package.json` 的 `version`（例如 2.1.1；次版號與修訂號須 ≤ 99）。
2. `npm run build`：建置網頁版並用本機金鑰簽署 APK。
3. `git commit` ＋ `git push`：GitHub Actions 會自動重建並部署下載頁與網頁版（GitHub Pages）。
4. `npm run release -- --notes "更新內容"`：用 GitHub CLI 把 APK 上傳成新的 Release。下載頁、QR Code 與 `releases/latest/download/NeonBastion.apk` 永遠指向最新版，不需要改任何連結。

手機重新下載安裝即可覆蓋更新，存檔會保留（v1 存檔的關卡星數會自動轉換，進行中的 v1 對局則無法接續）。

APK 只在本機簽署（GitHub Actions 只建網頁版），簽署金鑰永遠不會上傳。Fork 此專案的人第一次執行 `npm run build:apk` 會自動產生自己的金鑰。

### ⚠ 簽署金鑰

`android/keystore/` 裡的 `release.jks` 與 `keystore.properties` 是 App 的簽署金鑰。**請備份，且不要上傳到公開的地方。** 之後的更新版必須用同一把金鑰簽署，手機才能直接覆蓋安裝；金鑰遺失就只能先解除安裝（存檔會消失）。

## 遊戲說明

- **出擊編成**：戰役選關 → 部署畫面選難度、查看敵情（點敵人圖示看弱點），並從已解鎖的砲塔中挑 6 種帶上場（長按砲塔卡可看詳細資料）。
- **建造**：點路徑旁有發光角標的空地 → 環形選單選砲塔（第一次點預覽射程與數值，再點一次確認）。◆ 金色能量節點上的砲塔傷害 +20%、射程 +12%。
- **殘骸**：地圖上的殘骸要花資金清除後才能建造，有些殘骸下面藏著能量節點。
- **升級**：1～3 級一般升級 → 第 4 級選專精 A／B → 第 5 級終極型態（需先在研究所研究該砲塔的「終極協議」）。可切換索敵模式（最前／最後／最強／最近）。
- **老兵**：砲塔造成的傷害（含增幅與標記的助攻）累積戰功，晉升 ★／★★／★★★ 後傷害與射程提升。
- **傷害剋制**：點敵人可看它的裝甲類型與弱點；重裝甲另有「護甲值」會從每一發扣除（持續傷害與無視裝甲攻擊不受影響）。隱形敵人必須靠感測陣列偵測，範圍爆炸與雷霆審判也能短暫暴露它們。
- **波次與利息**：右下角「下一波」。提早呼叫可拿額外資金；每波開始時依存款給利息（上限隨波次提升）。本關會出現的敵人與首領可在出擊前的部署畫面查看。
- **技能**（左下角）：黃色「雷霆審判」閃電轟擊全場所有敵人（傷害隨波次成長、無視護甲、對護盾加倍、短暫麻痺並暴露隱形，首領只受一半），冷卻 120 秒；藍色「時停力場」全場敵人大幅減速 5 秒，冷卻 95 秒。
- **星星**：每關普通／困難／惡夢各 3 星（依核心剩餘耐久）＋ 挑戰任務 1 星。通關普通解鎖困難，通關困難解鎖惡夢（惡夢另有 2 個隨機突變：再生／護盾／疾速／重甲）。星星在研究所換永久強化，可隨時重置重配。
- **操作**：單指拖曳平移、雙指縮放；電腦版可用滾輪縮放、空白鍵開始波次、F 切換速度、1 雷霆審判、2 時停力場、Esc 暫停。

## 雙人對戰（v2.2）

標題畫面 →「雙人對戰」。兩種玩法：**線上對戰**（輸入相同的 5 位數房間號碼，任何網路皆可）與**練習對戰**（對電腦，簡單／普通／困難）。

- **地圖**：鏡像對稱的「雙子要塞」，左半是你（青色）、右半是對手（洋紅），各自只能在**自己的半場**建造。
- **系統波次**：每 25 秒雙方同時迎來完全相同的波次；第 14 波後進入驟死期，波次血量每波 +40%，對局約 10 分鐘分出勝負。
- **派兵列**（畫面下方）：每個按鈕顯示「怪物 ×數量」與價格，例如「步行機甲 ×6　160」。派兵會把怪物送進對手的路線，同時**永久提高你的收入**（每 6 秒入帳，上限 +300）。對手擊殺你送來的怪物只拿一半賞金。

| 兵種 | 數量 | 價格 | 收入 | 解鎖 | 定位 |
| --- | --- | --- | --- | --- | --- |
| 偵察無人機 | ×8 | 110 | +5 | 第 1 波 | 收入型：回報最好 |
| 步行機甲 | ×6 | 160 | +7 | 第 1 波 | 收入型 |
| 攻擊艇 | ×5 | 180 | +6 | 第 2 波 | 專打弱點：沒有防空就擋不住 |
| 護盾機 | ×4 | 190 | +6 | 第 3 波 | 專打弱點：沒有電磁傷害很難破盾 |
| 幽影 | ×4 | 210 | +7 | 第 4 波 | 專打弱點：沒有感測陣列打不到 |
| 重裝坦克 | ×3 | 240 | +6 | 第 6 波 | 重壓型 |
| 蜂巢艦 | ×2 | 230 | +5 | 第 8 波 | 重壓型（空中） |
| 主宰者 | ×2 | 300 | +7 | 第 10 波 | 重壓型 |
| 巨像（首領） | ×1 | 850 | +18 | 第 14 波 | 終結技 |

- **公平規則**：雙方起始 600 資金、收入 +25／6 秒、核心 40；不套用研究所加成，所有終極型態皆可升級；開戰前各自選 6 種砲塔。
- **平衡驗證**：`node tools/versus-sim.mjs --matrix` 讓 AI 以四種風格（均衡／經濟／龜縮／速攻）互打。同風格鏡像對戰約 50:50（60 場 29:31）；三種會派兵的風格互相約 4～6 成勝率，只守不派兵的龜縮打法必輸——派兵與收入的取捨就是勝負關鍵。
- **連線**：沒有自架伺服器。房間訊息經由公開的 MQTT 中繼伺服器（EMQX／HiveMQ／Mosquitto，三台自動備援）轉送；每位玩家只模擬自己的半場，再把快照同步給對方顯示。網頁版可以用 `…/play/?room=12345` 的連結直接邀請朋友。

## 音效與配樂

全部由程式合成，沒有任何音檔：首次啟動時在背景用 OfflineAudioContext 渲染音效與配樂（約 60 MB 解碼後音訊），存進 IndexedDB 快取，之後啟動約 0.5 秒就緒。

- **音效**：57 種、108 個變體，每個都是「瞬態＋主體＋尾音」分層設計；爆炸依規模分三級（大型含立體聲與次低頻衝擊）。同類音效連發會自動衰減，重擊時武器音軌會短暫側鏈閃避，全域最多 30 個聲部。
- **配樂**：選單曲〈Neon Horizon〉（84 BPM）、戰鬥曲（122 BPM，BED／DRUMS／HEAT 三軌分層）、首領戰曲。段落依小節無縫接續；建造階段只有濾波後的底層，開戰時鼓組在小節線上切入，HEAT 層隨場上壓力即時加強。
- **過場**：波次開始、首領登場、勝利、失敗，都對齊音樂小節。
- 手機第一次啟動約需 25～40 秒完成合成（背景進行，標題畫面右下角顯示「音軌合成中 xx%」），在那之前部分音樂尚未就緒。
- 修改 `game/src/audio/` 的合成或編曲後，要把 `audio.js` 的 `ENGINE_VERSION` 改版，玩家端才會重新合成。
